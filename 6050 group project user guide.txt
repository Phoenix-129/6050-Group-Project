1. OVERVIEW
================================================================================

This program allows users to extract and explore demographic data from the
U.S. Census Bureau (and, where applicable, the American Community Survey)
organized by county Federal Information Processing Standards (FIP) code. It is 
designed for students, community organizations, grant writers, and researchers who 
need a quick, straightforward way to pull demographic information for specific FIP 
codes without navigating the full Census website.

Users can enter a FIP code for an area of Michigan and receive a summary of 
relevant demographic data, such as number of residents without healthcare, internet 
access, number of residents below the federal poverty line, and median household 
income. For a full list of available variables, see Section 6 of this User Guide.

5. INPUT REQUIREMENTS
================================================================================

- FIP codes must be entered as 5-digit numbers (e.g., 48201).
- Only zip codes within Michigan are supported in
  this version of the program.
- If invalid input is entered (e.g., letters, incomplete zip codes, or zip
  codes outside the supported area), the program will display an error
  message and prompt you to try again rather than crashing.

================================================================================
6. AVAILABLE DATA
================================================================================

The following variables can be accessed for demographic data at the county-level:
- Median household income
- Number of individuals below the poverty line
- Number of individuals who are unemployed
- Number of individuals who are disabled
- Number of individuals without healthcare
- Number of households without a vehicle
- Number of households on any government assistance
- Number of households with computers or internet access
- Number of individuals who own their home
- Number of individuals >25 years of age with <9th grade education
